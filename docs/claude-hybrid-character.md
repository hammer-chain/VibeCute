# Claude Code 工服混合角色

开发模式中的角色为「Claude Code工服 · 混合分层（试验版）」，ID 为 `blue-fish-claude-hybrid`。思考动画采用原版像素身体、独立头部和连续变形头发。原像素工服角色及全 Cutout 角色继续保留。

## 素材与遮挡

`HybridHoodieArtwork` 从原版 `OrangeHoodieThinking/thinking-atlas.png` 的 8 帧分配身体、头部、头发的可见像素。原图集没有修改。身体包含衣服、抬手、腿、鞋袜与尾巴；头发层保留发饰及两侧耳部外轮廓。

`HybridHoodieThinking` 使用原版中性脸和原版半闭眼、闭眼区域。眼部先对齐中性脸坐标，再羽化衔接，避免直接切换整张倾斜脸时在刘海边缘出现旧轮廓。进入倾头时不切换整套人物画面。

补图使用内置 imagegen，源图与说明在 `artwork/hybrid-hoodie/`。`scripts/artwork/prepare_hybrid_hoodie.swift` 把源图注册为两张运行时垫图：

- `body-underpainting.png`：只垫在肩膀、领口和脖子后面；原版可见身体盖在上面。
- `face-underpainting.png`：补被刘海和手遮住的脸部，保留原版可见脸与表情。

抬手有紧凑的原像素前景层，最后绘制。头部层中误分到的手指顶部，以及身体层中残留的下巴边缘，在准备或绘制阶段排除，避免转头后出现漂浮线条和固定旧轮廓。补图范围仅覆盖当前思考动作需要露出的部位，不是完整的自由转头或换发型素材。

## 动作与入口

循环为 2.88 秒，身体使用原版 160 ms 节拍。0.96–1.12 秒连续倾头至 9°，1.44 秒半闭眼，1.60 秒闭眼并开始回正，1.76 秒完成回正。此后头部保持固定，只让长发末端衰减晃动，2.64 秒发梢稳定，最后 160 ms 锁定原版入口姿态。

正常角色在 30 Hz 时钟下采样。收到停止思考请求后完成当前循环，再回到原版待机姿态；切换角色会立即结束旧角色时钟。原像素角色的播放及停止逻辑保持原样。混合思考期间使用动作自身表情，待机继续使用原有视线和口型功能。

角色选择入口位于开发模式。开发窗口的「工服混合分层工作台」提供同步原版对照、时间轴、暂停续播，以及身体、头部、头发显示开关。启动参数为 `--hybrid-hoodie-workbench`，独立窗口参数为 `--hybrid-hoodie-studio`。

## 渲染开销

头发采用连续逆向坐标采样，每个输出像素只采样一次，无条带接边。首次尝试的 Core Image 路径在本机隔离测试中 p95 约 271 ms，已替换为按行预计算三角函数的双线性采样，最终 p95 约 2.20 ms。

文件读取、解码和分层只在准备阶段执行。运行时只缓存最近一张变形头发与合成画面，不保留完整动画图集。静态分层、准备数据和两张缓存合计 30,724,992 字节，上限 32 MiB。手的裁片复制到独立紧凑缓冲，避免 `CGImage.cropping` 保留整张父图而漏算内存。以上为本机隔离绘制与应用自有像素缓存口径，不代表整个应用内存或 CPU。

## 验证

- `bash scripts/hybrid_thinking_check.sh`：72 个动画采样、504 个身体与抬手锚点、颈部覆盖、34 次回正后头部锁定检查、独立头发运动、首尾一致。身体锚点最大通道差为 2，来自原图半透明像素的叠加；颈部区域最低 alpha 为 253。
- `bash scripts/hybrid_thinking_native_check.sh`：原生播放器身体节拍、结束后待机、重启、角色切换，以及原像素角色仍立即停止。
- `bash scripts/orange_hoodie_checks.sh`：原像素角色 108 种视线／口型组合、身体和思考帧回归。
- 签名开发版工作台实窗检查倾头、闭眼、回正与图层开关。渲染对照 GIF、接触表、日志和截图在 `output/hybrid-hoodie/thinking/` 及相邻日志文件。

本轮只交付该角色的思考循环。更大角度转头、替换发型或其他动作，需要重新检查并补全新的遮挡区域。
