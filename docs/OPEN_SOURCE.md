# 开源前检查与源码导出

## 检查入口

```sh
python3 scripts/source_audit.py --history
# 同时导出无 Git 历史的源码包
python3 scripts/source_audit.py --history --export
```

审计范围是当前存在的已跟踪文件，以及未被 Git 忽略的未跟踪文件。已删除文件不进入源码导出。历史检查遍历所有本地分支和标签可达的唯一对象，不包含 Git 不可达对象、其他工作树的未提交内容或远端仓库。

审计检查常见凭据格式、私钥、个人绝对路径、本地专用文件、GitHub 单文件大小限制、符号链接和 PNG 附属元数据。发现疑似凭据时只记录位置和规则，不打印内容。扫描规则不是绝无敏感信息的证明，发布前仍应人工复核提交 diff 和新增素材。

结果位于被忽略的 `output/open-source-audit/`：

- `audit.json`：当前文件、可选历史检查及导出结果。
- `export-manifest.json`：导出文件路径、大小和 SHA-256。
- `VibeCute-source.zip`：通过当前文件检查后生成的源码包，不带 `.git` 或扩展属性；每个文件均解压回读并核对哈希。

扫描及导出只在手动执行时运行，不增加 App 运行期开销。历史按唯一对象读取，避免逐提交重复扫描。源码导出会再次核对读取内容，期间不要修改源码。

## 本地内容与历史的区别

`.gitignore` 防止新的本地文件被误加入，但不能从历史中移除已有内容。被忽略的 `backups/` 保存本地交接历史、生成提示词、退役角色和元数据清理前的原图；`dist/`、`output/`、`.build/`、会话日志、账户与签名文件均不应提交。

当前源码中的图片清理仅移除附属 EXIF／文本／生成溯源元数据，不更改 IDAT 压缩像素数据。角色署名在 README 和 LICENSE-ASSETS.md 中保留。

现有开发历史仍可能包含已删除的提示词、旧角色和旧图片元数据。**清理工作区不等于清理历史。** 如希望首次公开仓库不携带这些记录，使用本脚本生成的源码 ZIP，在新目录解压后创建新的 Git 仓库：

```sh
# 在解压后的 VibeCute 目录执行；不是现有开发仓库
# 不要将 ZIP 本身作为 Git 源码文件提交
git init -b main
git add .
git diff --cached --stat
# 人工复核待提交内容，再创建首次提交
```

不要把现有仓库的 `.git`、本地备份或构建目录复制过去。脚本不会改写现有历史，不会提交、推送或创建 GitHub 仓库。若未来发现真实凭据曾提交，应先撤销或轮换凭据，再处理历史；只删除当前文件不够。
