# 首次启动引导设计

状态：已实现，验收范围见文末记录。目标是让用户先认识、互动蓝色大肥鱼，再自行选择权限和 AI 连接。首次启动只创建一个独立角色；不跟踪任何 Harness。

## 01 · 初始状态

新安装：独立角色开启，角色为蓝色大肥鱼；trackedHarnesses 为空。系统声音、屏幕感知、语音识别均先关闭，避免问候前弹出权限请求。未连接时不扫描 Harness 日志、不启动豆包读取、不启动音频采集或屏幕抓取。

已有安装：保留已存配置，不因新增引导标记缺失而清空绑定。用既有偏好键是否存在识别升级用户；后续提供菜单“重新查看新手引导”，重看时不覆盖配置。

引导字幕固定在鱼旁，按钮可点击、不随字幕超时消失。字幕不会被后台工作状态覆盖。每次只出现一段文案；支持键盘焦点、回车激活主按钮。屏幕边缘自动调整气泡位置，按钮不出屏幕。

## 02 · 问候

**字幕：**

你好呀 👋 我是蓝色大肥鱼！
以后就让我在桌面上陪你吧～

**按钮：**「你好呀！」

鱼播放现有欢迎或开心动作；按钮进入下一步。复用已有动画素材，缺少专用欢迎动作时使用现有待机表情，不以新增素材阻塞实现。

## 03 · 权限邀请

**字幕：**

现在的我还看不到桌面，也听不到电脑的声音。

如果你愿意给我一点权限，我就能对屏幕和声音做出反应啦！

**按钮：**「好呀，开始设置」「以后再说」

开始设置：打开 VibeCute 的“让大肥鱼认识桌面”设置窗口，保留桌面角色；窗口内有屏幕、声音两项及当前状态。每项独立申请，逐项触发系统弹窗或打开对应系统设置页，避免连续堆叠弹窗。

- 屏幕：“让我看到桌面” → 已有屏幕权限请求入口；需要时打开系统设置对应页面；实际读取成功才显示已就绪。
- 声音：“让我听到电脑声音” → 启动用户选择的系统音频功能，触发系统录音授权；捕获成功后显示已就绪。授权等待或失败不重试循环。静音不等于未授权；以采集运行结果判断，不能要求一定有音量。
- 窗口按钮：「继续」「以后再说」。继续始终可用，无权限也能继续。
- 提示：“可以只开启一项，也可以以后再设置。”

本轮不申请辅助功能、Apple 语音识别或控制终端的自动化权限。这些权限等用户启用豆包、语音关键词或终端跳转时再申请。

返回应用或点击状态刷新时检查权限及实际能力；不使用持续轮询。授权尚未完成不能自动跨步；两项成功后展示就绪状态，由用户点击继续。

## 04 · 就绪与跳过分支

两项可用：

> 好耶，准备就绪！ ✨
> 试试用鼠标摸摸我，或者把我拖到喜欢的位置吧～

仅屏幕可用：

> 好耶，我能看到桌面啦！ ✨
> 声音可以以后再设置。
> 试试用鼠标摸摸我，或者把我拖到喜欢的位置吧～

仅声音可用：

> 好耶，我能听到电脑的声音啦！ ✨
> 屏幕可以以后再设置。
> 试试用鼠标摸摸我，或者把我拖到喜欢的位置吧～

两项都跳过、拒绝或失败：

> 没关系，我们先认识一下！
> 试试用鼠标摸摸我，或者把我拖到喜欢的位置吧～

权限窗口关闭视为暂缓设置，进入互动；失败状态给出设置入口，用户仍可继续。某项已授权时不重复申请。

## 05 · 互动体验

任意一种真实角色互动即可完成本步，不要求全部体验：

| 互动 | 动作与表情 | 完成事件 |
|---|---|---|
| 点击角色 | 复用可用的短反馈表情或动作 | 角色区域点击完成 |
| 悬停角色 | 注视鼠标、现有悬停反馈 | 角色区域连续悬停 0.8 秒；这是设计阈值 |
| 摸摸头 | 复用摸头反应 | 已有摸头识别成功 |
| 拖动角色 | 复用拖动划水与落地动作 | 实际移动后松开，保存位置 |

点击引导按钮不算角色互动。单次互动只推进一次；拖动过程中不切换字幕、不抢焦点，松开并结束落地反应后进入下一段。

**字幕：**

嘿嘿，我喜欢这里！

**按钮：**「继续」

等待互动时提供低强调按钮「先继续」，用户可以绕过。不要用自动倒计时让用户错过互动。

## 06 · 连接 AI 助手（可选）

**字幕：**

对啦，如果你平时用 Codex、Claude Code 这些 AI 工具……

我还可以同步它们的工作进度。

想现在连接一个吗？

**按钮：**「连接 AI 工具」「以后再说」

连接：打开应用连接设置，只预选用户选择的一个工具，蓝色大肥鱼为默认角色。选择工具还不启动跟踪，用户点击“连接”后才启用该 Harness。连接失败或没有发现会话时明确显示“已开启，等待会话”或真实错误，不能称为连接成功。

独立角色转为该 Harness 的角色时，沿用位置和大小，确保没有两个重叠的蓝色大肥鱼。确认连接前保留独立角色；取消、关闭连接窗口时也保留它。后续会话空闲或退出仍保持陪伴角色可见；是否隐藏必须由用户明确设置。

若所选工具需要额外权限，先解释对应功能，再申请；本步骤默认的 Codex/Claude Code 日志跟踪不索取辅助功能权限。

**选择以后再说或取消：**

没关系！我先在桌面上陪你。

想连接的时候，随时来找我就好～

**按钮：**「继续」

**成功启用跟踪：**

好啦，我会留意它的工作进度！

**等待会话：**

已经设置好啦，等你开始使用，我就能跟上进度！

这两个结果均提供「继续」；无法启用则保留错误与「重试」「以后再说」。

## 07 · 引导结束

**动画：** 结束短反馈，回到默认待机。

**字幕：**

那么，从今天开始，请多关照啦！💙

**按钮：**「开始与蓝色大肥鱼一起生活」

点击后清除引导气泡、持久化完成标记，保留位置、实际授权功能和用户确认的连接。未连接则继续独立陪伴。菜单提供“权限设置”“连接 AI 工具”“重新查看新手引导”。

## 生命周期与性能验收

有限状态：问候 → 权限邀请 → 权限窗口/暂缓 → 互动 → 互动反馈 → 可选连接 → 告别 → 完成。

保存引导版本与最后可恢复步骤。关闭应用后再次打开恢复当前步骤；授权等待恢复时先验证能力，拖动或动画中断恢复到互动等待。连接已经确认但退出时不重复连接。最终完成前不能写完成标记。应用升级不重跑、不覆盖旧配置。重新查看只重播教学，保留绑定与功能状态；已授权时使用符合当前能力的文案。

性能约束：固定数量的状态和控件；复用角色动画时钟与既有鼠标事件；悬停使用一个可取消的一次性计时，离开、切步或结束即释放。引导退出移除订阅和计时器，不新增常驻轮询。未启用的功能零采集、零 Harness 扫描；已开启的声音/屏幕成本另列。

实现验收：全新偏好、升级偏好、两个权限成功/单项成功/拒绝/跳过、静音采集、设置窗口关闭、点击/悬停/摸头/拖动/跳过互动、连接成功/等待会话/失败/取消、中途退出恢复、完成后重启、跨屏拖动和气泡边界。只允许一个鱼角色；字幕与按钮稳定可操作。

性能验收：相同机器与音频/屏幕配置下，对比独立陪伴基线、引导等待、互动及结束后的短时 CPU/RSS；检查引导结束无遗留计时与订阅。设计目标是结束后开销回到原陪伴基线；容许波动需在测量后确定。具体实测与未验收范围见文末记录和验收报告。

## 实现记录 · 2026-10-14

已实现。引导字幕复用摸头动画的 SubtitleView 与 AkimboDialogue 侧边定位，按钮复用 BubbleReplyButton。屏幕和声音设置、AI 连接选择仍是单独窗口。引导期间抑制普通工作字幕和摸头长对白，保留角色动作。

新安装默认独立蓝色大肥鱼、零 Harness 跟踪、关闭采集；已有配置跳过自动引导。连接页提供 Codex、Claude Code、DeepSeek Harness，其余工具可从常规设置连接。连接结果与当前步骤可恢复，重看不会修改完成标记。位置记忆使用当前偏好域，隔离测试不写入个人位置配置。

检查命令：`python3 scripts/onboarding_checks.py`、`bash scripts/test.sh`。原生受控检查需要 WindowServer；测试使用随机偏好域并在结束时清理。运行开销可用 `python3 scripts/onboarding_performance.py PID --seconds 30 --output output/metrics.json` 复测。

验收报告：output/performance-audit/onboarding-verification.html。系统首次授权、权限拒绝后不同 macOS 版本的提示与返回行为仍需未授权环境验证；此边界不能以状态检查替代。
