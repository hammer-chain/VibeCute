# 蓝鱼顶盆避雨动作

用户于 2026-10-18 确认 v5 动作帧可用。资源为内置图像生成工具参考现有蓝鱼绘制的完整角色帧，不包含 v4 的分离腿袜/鞋子拼装。

- `Sources/CodexCaptions/Resources/DeepSeekThinking/RainShelter/frame-01.png` 至 `frame-08.png`：拿盆、翻扣头顶、起身，0.2 秒/帧。
- `frame-09.png` 至 `frame-16.png`：顶盆小跑，0.1 秒/帧，可循环，行进方向朝左时整体镜像。
- `frame-17.png` 至 `frame-24.png`：减速、摘盆、放盆、坐下，0.25 秒/帧。
- `frame-25.png` 至 `frame-32.png`：伸手收盆、盆移入裙摆/尾巴后方、接回原思考姿势，0.15 秒/帧。结束后释放雨姿势覆盖，使用原来的思考帧计时器。

每帧 512×640，RGBA 透明 PNG，足底参考线 y=608。离线放大原绘画、补透明边距；跑步八帧共用相同倍率，较小的后段坐姿另作补偿。亮蓝头发饱和度最多降低18%、亮度最多降低4%，眼睛用平滑遮罩保护。原生绘制共用固定画布，不实时缩放单条腿或调色。最后一帧匹配原168点思考画布及其脚下留白。蓝鱼透明角色窗口宽204点，正常思考画面仍为126×168点，避免放大后裁掉盆和头发。

`scripts/calibrate_rain_artwork.py`（作者工具，需要 Pillow）从已确认的原始提交 `6023e7c` 读取24张图，不读取校准后的输出，重复执行不会叠加偏色/缩放。缺少该历史时可用 `--source-dir` 指定原始24帧目录；`--output` 可输出到临时目录进行校验。`calibration.json` 保存规则和输出哈希。收盆仅复用现有完整姿势和盆图层，没有新生成美术，也没有拆装腿部。

左右朝向共用同一组缓存，不复制像素。32帧共享解码的上限40 MiB，冷加载预算250ms；运行仍为最多30Hz移动、每角色最多2Hz规划，共享雨效原有窗口缓存，无新增网络/窗口查询。

目标位置必须让全部动作及恢复思考后的角色留在前台普通窗口内部。无论起点高低、是否已在窗口内部，一律取底边内侧8点（随角色比例缩放），横向选择最近的可容纳位置。过窄、过矮、底边不可达或屏幕约束下放不进去的窗口触发当前位置左右56点往返。

原始生成提示词作为本地开发记录保留，不随资源包分发。导出PNG不含EXIF/文本元数据。角色既有美术署名沿用主项目。
