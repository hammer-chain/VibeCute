# 平常坐姿视线层

来源：用户提供的 `animation/DeepSeek_视线跟随`，原包记录在
`output/seated-gaze/reference-config.json`。三张 PNG 原样复制，无新增生成图或生成提示词。

- `eye-white-source.png`：保留原包 `layers/base.png` 供复查。运行时使用缓存渐变，在当前帧的完整眼睛开口内绘制不透明眼白，避免原图瞳孔边缘残留；不再从这张含眼缘与皮肤的整图取眼白。
- `pupil-left-mask.png`、`pupil-right-mask.png`：原包 `eyes/pupil-*.png`，只使用 Alpha；瞳孔 RGB 从项目无损坐姿第一帧恢复，避免 GIF 调色板改变蓝色。
- 原包画布 448×640，原图放在 (32,112)。加载时裁回 384×512，按现有坐姿显示矩形等比绘制，禁止按新增留白放大角色。
- 身体固定使用已确认的坐姿第一帧；眨眼仅从现有图集第 3、4 帧取眼眶内局部，沿用原播放时钟。
- 口型继续使用现有 12 个口型、锚点和音频状态机，独立于视线状态。

视线只用于 DeepSeek 原有扶下巴坐姿，包括说话时的该坐姿。小跑、表演、坐姿挪动、挪动后的另一种坐姿及粉色小熊沿用各自素材。默认读取全桌面光标；应用失焦不回中，因为桌面角色需要跟随其他窗口中的光标。动作切换时视线平滑回中，角色隐藏时停止更新。

眼部中心为原图左上坐标 (174,204)。源像素最大位移为 X±4.4、Y±3.2；椭圆归一化半径 190×145，死区 0.035，跟随时间常数 0.095 秒，回中 0.18 秒。先逆变换呼吸，再从实际显示矩形还原源坐标；屏幕坐标支持负值和多显示器。

验证：`bash scripts/geometry_test.sh --gaze-only`，随后 `python3 scripts/seated_gaze_smoke_test.py`。原生检查需要图形会话。结果与连续预览见 `output/seated-gaze/`。
